# Identity Benchmark V1

Versioned files in this directory are the adjudicated labels and their lock
metadata. Generated crop sheets, HTML and reports belong under
`evaluation_outputs/identity_benchmark_v1/` and are intentionally ignored.

## 1. Build the frozen annotation set

Run where the videos, crops and run artifacts are available:

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/home/cappetti/FT \
python3 scripts/build_identity_benchmark.py \
  --spec evaluation/identity_benchmark_v1.yaml
```

The builder fails if a declared roster, tracklet table, run manifest or pair
diagnostic is missing. `benchmark_manifest.json` records SHA-256 hashes for
every input.

## 2. Annotate

Open:

```text
evaluation_outputs/identity_benchmark_v1/annotate_reviewer_a.html
evaluation_outputs/identity_benchmark_v1/annotate_reviewer_b.html
```

Reviewer A labels all items. Reviewer B labels only the deterministic,
stratified 20% subset. Predictions, confidence and source are absent from the
HTML payload. Download the two CSV files into the `annotations/` directory.

## 3. Adjudicate and freeze

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/home/cappetti/FT \
python3 scripts/adjudicate_identity_benchmark.py
```

If reviewers disagree, the command writes `adjudication_required.csv` and
exits with status 2. Fill those rows as adjudicator, pass the file with
`--adjudication`, then commit:

```text
evaluation/identity_benchmark_v1/ground_truth.csv
evaluation/identity_benchmark_v1/ground_truth_manifest.json
evaluation/identity_benchmark_v1/agreement_report.json
```

## 4. Evaluate baseline and candidate

Every evaluated run must contain:

```text
{video_id}_tracklets.csv
{video_id}_constraints.json
{video_id}_identity_preconstraint_state.csv
```

The pre-constraint artifact is generated by the current pipeline. Historical
runs without it can be used to build annotation sheets, but cannot pass the
final promotion gate.

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/home/cappetti/FT \
python3 scripts/evaluate_identity_benchmark.py \
  --baseline Int-Ata=BASELINE_INT_ATA \
  --baseline Inter-Juve=BASELINE_INTER_JUVE \
  --baseline Inter-Atalanta=BASELINE_INTER_ATALANTA \
  --candidate Int-Ata=CANDIDATE_INT_ATA \
  --candidate Inter-Juve=CANDIDATE_INTER_JUVE \
  --candidate Inter-Atalanta=CANDIDATE_INTER_ATALANTA
```

Int-Ata is always excluded from final promotion metrics. It remains available
in the per-unit CSV for development diagnostics.
